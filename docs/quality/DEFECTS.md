### Генератор кандидатов падал на 10 из 17 стеков

- **Обнаружено:** 2026-08-03, ревью базы и стандарта
- **Исправлено:** 2026-08-03, ветка `fix/audit-2026-08-03`
- **Root cause:** `new_candidate.BODY_LABELS` — вторая копия таблицы подписей,
  оставшаяся на семи стеках после того, как `validate.BODY_FIELDS` вырос до
  семнадцати (commit `ff54781`, 2026-07-08). `--stack` предлагал все семнадцать,
  и десять из них давали `KeyError`. Не поймано, потому что тесты вызывали
  генератор только со стеком `common`, — а harvest-скилл называет этот генератор
  единственным способом создать кандидата и отдельно требует предпочитать
  конкретный стек вместо `common`, то есть вёл ровно в падение. Жило четыре
  недели.
- **Исправление:** таблица одна — `BODY_LABELS = validate.BODY_FIELDS`. Тест
  проходит по всем `ALLOWED_STACKS` и требует, чтобы сгенерированный кандидат
  проходил собственный валидатор. Проверено откатом: на старом коде падает ровно
  на десяти стеках.

### Матрица переходов статусов не вызывалась ниоткуда

- **Обнаружено:** 2026-08-03, ревью базы и стандарта
- **Исправлено:** 2026-08-03, ветка `fix/audit-2026-08-03`
- **Root cause:** `ALLOWED_PRACTICE_TRANSITIONS` и `practice_transition_allowed`
  существовали, но вызывались только собственным юнит-тестом. `validate_practice`
  читает одну ревизию и предыдущего статуса не видит в принципе, поэтому пункт 1
  ADR-0005 (`superseded` терминален, `accepted` не возвращается в `trial`) был
  неисполним: правка `status: accepted` → `status: trial` проходила `make check`
  без жалоб. Тест проверял словарь, а не защиту, и оставался зелёным при
  полностью нерабочем инварианте.
- **Исправление:** `validate.py --history-base <ref>` читает предыдущий статус
  из git и применяет матрицу; база, которую не удалось прочитать, — ошибка, а не
  молчаливый пропуск. `validate.yml` передаёт базу pull request при
  `fetch-depth: 0`. Проверено на живом репозитории: `accepted → trial` теперь
  отклоняется с указанием ADR.

### Свежесть не влияла на доставку и не проверялась по расписанию

- **Обнаружено:** 2026-08-03, ревью базы и стандарта
- **Исправлено:** 2026-08-03, ветка `fix/audit-2026-08-03`
- **Root cause:** `practice_report` отбирал практики только по статусу и поле
  `review_by` не читал вовсе — просроченная практика уходила в проект как
  актуальная. При этом `--strict-freshness` запускался только на `pull_request`

- **Исправление:** доставка помечает просроченную практику (`stale`, видимая
  строка в отчёте) вместо того, чтобы прятать её; отдельный `freshness.yml`
  проверяет просрочку по расписанию.

### `validate.yml` оставлял токен в рабочем дереве

- **Обнаружено:** 2026-08-03, ревью базы и стандарта
- **Исправлено:** 2026-08-03, ветка `fix/audit-2026-08-03`
- **Root cause:** `persist-credentials: false` стоял в `governance-audit.yml` и
  отсутствовал в `validate.yml`; собственный contract-тест проверял права и пины,
  но не это. Джоба исполняет код репозитория с токеном в `.git/config`. Как
  эксплойт — низкий риск (публичный репозиторий, `contents: read`, триггер
  `pull_request`), как инвариант — дыра: добавление `contents: write` завтра
  тест бы пропустил. Стандарт требует того же от себя с самого начала.
- **Исправление:** флаг проставлен, тест требует его от каждого checkout в
  каждом workflow.

### Matrix CI переименовала обязательный ruleset check

- **Обнаружено:** 2026-07-14, review cross-platform workflow
- **Исправлено:** 2026-07-14, текущий commit
- **Root cause:** job `validate` напрямую превратили в matrix, поэтому GitHub

### JSON report падал в Windows-консоли с legacy encoding

- **Обнаружено:** 2026-07-14, smoke-test исправления Windows validator
- **Исправлено:** 2026-07-14, текущий commit
- **Root cause:** CLI печатал Unicode JSON через системный `cp1251`; символы из

### Windows validator отклонял canonical candidate targets

- **Обнаружено:** 2026-07-14, создание consumer-проекта `favorit-web`
- **Исправлено:** 2026-07-14, текущий commit
- **Root cause:** pair-validation сравнивал POSIX-путь из поля `target` со
  `str(Path.relative_to(...))`; на Windows второй путь содержал обратные слэши,

- **Исправление:** repository paths сериализуются через `.as_posix()`, regression
  закрепляет canonical форму, а полный gate выполняется на Windows, Linux и macOS.
